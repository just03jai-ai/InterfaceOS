# InterfaceOS Roadmap

The roadmap is outcome-based; dates are assigned only after capacity and owners are approved.

| Milestone                                      | Outcome                                                                | Entry gate                                                 | Exit evidence                                                             | Status      |
| ---------------------------------------------- | ---------------------------------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------- | ----------- |
| Foundation audit                               | Trusted repository contracts, standards, governance, and quality gates | Repository access                                          | Passing checks and approved audit                                         | In review   |
| [IOS-001](ios-001-design-foundations.md)       | Approved design foundations and token architecture                     | Foundation audit approved; Figma file and owners available | Token, Figma, documentation, accessibility, build, and evidence approval  | Active      |
| [IOS-002](ios-002-figma-variable-execution.md) | Evidence-backed Figma variable execution                               | IOS-001 Stage 2 architecture and governance merged         | Approved variable batches with verified IDs, screenshots, and zero drift  | Active      |
| [IOS-003.1](ios-003-1-color-foundation.md)     | Approved Color Foundation V1 visual baseline                           | Foundation architecture and execution framework merged     | Human approval, Figma closure evidence, and controlled promotion boundary | Approved    |
| [IOS-004](ios-004-typography-foundation.md)    | Governed Typography Foundation visual and technical baseline           | IOS-003.1 approved; typography source and Figma available  | Typography mapping, specimens, validation, evidence, and approval         | Ready       |
| IOS-005                                        | Pattern, search, knowledge, governance, and analytics vertical slices  | Required components and stable artifact contracts          | Evidence-backed vertical slices with governed projections                 | Not defined |

Moving a milestone to active requires named owners, approved scope, dependencies, risks, acceptance criteria, and evidence plan. Later milestones remain intentionally unexpanded until prior learning is available.
