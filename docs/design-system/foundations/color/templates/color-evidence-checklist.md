# Color Foundation Evidence Checklist

Status: Template — absent or unverifiable evidence is blocked, not synchronized

## Source evidence

- [ ] Canonical primitive, semantic, theme, and contract paths
- [ ] Exact Git commit/revision
- [ ] Source checksums
- [ ] Token counts and names
- [ ] Alias graph and generated-output result
- [ ] Relevant ADRs and approved open-decision records

## Figma evidence

- [ ] Canonical file URL and verified file key
- [ ] `03 Foundations` page and Colors section node IDs
- [ ] Board/frame node IDs
- [ ] Collection, mode, and variable IDs where variables are referenced
- [ ] Figma revision/version
- [ ] Screenshots of primitive, semantic, theme, accessibility, dashboard, chart, review, and approval boards
- [ ] Evidence that proposals are separated from approved artifacts
- [ ] Unpublished library-state capture; file sharing permissions are recorded separately

## Validation evidence

- [ ] Schema validation
- [ ] Naming validation
- [ ] Duplicate primitive-value report
- [ ] Missing semantic/theme mapping report
- [ ] Alias/reference/cycle validation
- [ ] Contrast obligation report for Light and Dark
- [ ] Alpha-compositing results
- [ ] Color-vision and grayscale collision results
- [ ] Forced-colors test plan or implementation results
- [ ] Chart palette and complex-image/text-alternative results
- [ ] Full quality and build output

## Review evidence

- [ ] Design reviewer, date, result, and rationale
- [ ] Engineering specialist reviewer, date, and result
- [ ] Accessibility specialist reviewer, date, and result
- [ ] Governance reviewer, date, and result
- [ ] Independent final approver, date, and result
- [ ] Rejected options and trade-offs
- [ ] Exceptions with owner, expiry, remediation issue, and affected scope

## Synchronization evidence

- [ ] One Git revision and one Figma revision used for comparison
- [ ] Synchronization checksum
- [ ] Drift classification and resolution owner
- [ ] Re-run result after every correction
- [ ] Final `synchronized` state supported by complete evidence

## Privacy and integrity

- [ ] No credentials, private comments, personal data, or unrelated work appears in evidence
- [ ] No fabricated identifier or placeholder is marked captured
- [ ] Screenshots supplement rather than replace editable Figma evidence
- [ ] Third-party research is attributed and no proprietary values/assets are copied
