# `@interfaceos/tokens`

Canonical, platform-neutral InterfaceOS design tokens and deterministic exports.

## Commands

```sh
pnpm tokens:validate
pnpm tokens:build
```

Sources in `src/` are authoritative. `dist/` is generated and ignored by Git. Never edit generated CSS, JSON, TypeScript, or Tailwind output directly.

See the [token architecture](../../docs/design-system/tokens/token-architecture.md) before contributing.
